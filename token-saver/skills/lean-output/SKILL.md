---
name: lean-output
description: Token-saving habits. Use when the user asks to save tokens, be concise, or reduce cost.
---
- Answer first; no preamble, recap or closing offers. Keep replies short.
- Grep/Glob to locate, Read only needed ranges; don't re-read files in context.
- Batch independent tool calls; use small Edits.
- Skip subagents, plans and brainstorming for small tasks.
- Pick a sensible default instead of asking; state the assumption.
- Trim noisy command output (head/tail/grep).
- One task per session; /compact when long; cheaper model for simple work.
