# token-saver
Claude Code plugin: when session context exceeds 80k tokens, Claude asks whether to compact, clear, or switch model. Needs Node.js. Works on Mac/Windows/Linux.

    /plugin marketplace add <github-user>/token-saver
    /plugin install token-saver@token-saver-market

Tune: set env var TOKEN_SAVER_THRESHOLD (default 80000).
